# LIFE RPG (Life-hub)

Application personnelle de gamification de la vie réelle, pour un seul utilisateur.
Tout tourne en local : Django + DRF + SQLite, front React + TypeScript + Vite + Tailwind.

## Contenu du dépôt

| Fichier | Rôle |
| --- | --- |
| `docs/PROMPT_BUILD_LIFE_RPG.md` | Prompt de construction complet à donner à l'agent de code (Claude Code, etc.) |
| `docs/brand-book.html` | Brand book interactif : identité visuelle, tokens CSS et Tailwind, composants, motion. Ouvre-le dans un navigateur. |
| `docs/CAHIER_DES_CHARGES.md` | **À ajouter** : export Markdown du cahier des charges (voir ci-dessous) |

## Ajouter le cahier des charges

Le cahier des charges est un doc en ligne : https://claude.ai/artifact/1U2ioQ2rRC1MRuKtHiPpwu
Dans le doc, menu d'export, choisir Markdown, puis enregistrer le fichier sous `docs/CAHIER_DES_CHARGES.md`.
Un agent de code ne peut pas lire ce lien privé : le fichier doit être dans le dépôt.

## Démarrer

1. Vérifier que `docs/CAHIER_DES_CHARGES.md` est présent.
2. Ouvrir Claude Code à la racine du dépôt.
3. Coller le contenu de `docs/PROMPT_BUILD_LIFE_RPG.md`.
4. Valider le plan, puis chaque phase (0 à 4) l'une après l'autre.
